# Owner dashboard

Create /dashboard with a server-checked demo owner session and /owner-login. Use signed, expiring HttpOnly cookies, logout, same-origin checks and noindex metadata. Default credentials are expressly for a demo, not production identity verification.

Use browser-persisted sample operations and deterministic sample orders. Derive revenue, order statuses, payments, item rankings, repeat customers and peak times from the same filtered dataset. Provide day/week/month/year controls, interactive charts, searchable order and menu screens, editable stock/menu/staff/expenses/offers/reservations, review follow-up and website draft settings. Do not mutate the public menu or claim demo sales are real. Offer CSV for Excel and a print layout for PDF. Preserve keyboard access, mobile overflow containment and reduced motion. Verify auth boundaries, analytics, build and browser interactions.
