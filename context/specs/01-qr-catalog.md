# QR catalog
## Goal
Make it easy to choose a dish at the table.
## Design
See ui-context.md for the palette, typography, and layout.
## Implementation
Render curated highlights, menu-wide search, categories, dietary filters, and data-bound dish details. Use the supplied table URL for ordering.
## Dependencies
GSAP, Lenis, and static WebP photography.
## Verify when done
- [ ] Match every item, price and category to the captured catalog.
- [ ] Open and close dish details with touch and keyboard.
- [ ] Test search, empty state, category and diet selection, and pagination.
- [ ] Verify mobile and wide layouts, including reduced motion.
