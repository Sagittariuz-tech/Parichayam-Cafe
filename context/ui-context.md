# UI context
## Theme
A coastal café menu styled like a printed food journal with editorial photography and warm side light.
## Colors
Parchment #f6f1e7, deep forest #1b3026, rust #a3462d, muted ink #5e5e4f, sand #d8d1c2.
## Typography
Instrument Serif for display and DM Sans for reading, labels, and prices.
## Layout
Split feature on desktop, image beneath headline on phone. Horizontally scrollable featured cards and quick categories. Full menu with search, dietary filters, and a native category drawer. Keep buttons at least 44px tall.
