# Code standards
Use TypeScript, semantic landmarks, real controls, native dialogs, and visible keyboard focus. Keep menu data and search logic outside React components.
Render the catalog through React and use client effects for browser-only animation or native dialog control. Set image dimensions and lazy-load below the fold. Keep the layout usable at 320 CSS pixels and respect reduced motion.
Run npm run menu:build after changing menu-source.txt. Run npm run menu:verify and npm run build before handing off the site.
